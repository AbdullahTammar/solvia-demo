# Solvia — Hotel Operations Portal (prototype)

Static prototype for GitHub Pages. Open `index.html` or visit the Pages URL.

- Bilingual EN / AR (Cairo font, RTL), light and dark themes, Lucide icons
- Home dashboard, workflows and approvals, service desk (kanban board, SLA timers, guest channels)
- **Dev** section (password protected): edit services, integrations, hosting and prices, then copy a client link
- **Client proposal**: the client reviews, removes optional items, signs, approves, and sends the approval by WhatsApp or email
