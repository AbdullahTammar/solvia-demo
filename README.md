# AR SOLVIA — prototype

Static prototype hosted on GitHub Pages. No build step: open `index.html`.

- `#` public website · `#service/<id>` service details
- `#app/customer/...` customer (individual or company account, OTP sign-in)
- `#app/employee/...` employee · `#app/supervisor/...` supervisor
- `#pricing` hidden price page (password protected)

Data lives in `js/data.js` (services, platforms, tickets, pricing). Demo changes are saved in the browser's localStorage.
